# Historical Blaze CircuitLab source archives

These 14 ZIP files preserve the original development snapshots (v0.2.0 through v0.2.9), the earlier offline alpha update, the standalone topology/KiCad candidate and the v0.2.3 offline library/interop outputs. They are **historical source evidence**, not Android APK releases. The runnable native project is at repository root under `app/`. The Git blob identifiers for each archive are independently checked against the original local ZIP bytes. Do not publish an APK or merge PR #1 on the strength of these archives alone.
