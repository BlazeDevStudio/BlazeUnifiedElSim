# BlazeBasic local reference footprint library

Contains original, minimal .kicad_mod reference geometries drawn for Blaze CircuitLab.
These are preliminary package/pad patterns, not verified manufacturer footprints,
and MUST be checked against the selected physical part and KiCad DRC before fabrication.
No KiCad official library content or third-party component images are copied.
The official KiCad libraries are available separately under CC-BY-SA 4.0.
Arduino and Espressif pin names in the application are factual compatibility references,
not manufacturer software or design assets.
